How this workflow works
  1. Goal — you type or pick a plain-English automation goal.
  2. Search — the server queries Jira, Splunk, or the CRM directly; the model never chooses.
  3. Match — results are filtered against your goal's criteria (status, severity, priority…).
  4. Draft — Claude writes the comment, assignment, or message for each match.
  5. Validate — every target the model names is checked against the real search results.
  6. Review — you see each step's tool, target, and drafted text before anything happens.
  7. Approve / Reject — one click per step; rejecting never runs the tool.
  8. Execute — approved steps call the real Jira / Splunk / CRM / Slack / Gmail tool.
  9. Audit — actor, decision, and result are recorded immutably, either way.
